A phrase may append ONE owned ASCII separator after its payload only if ALL hold:
* policy.autoSpaces permits prose (not private/secure/address/numeric fields);
* BOTH host context sides are visible (empty visible is meaningful); logical reconciled context is used for own lag;
* original left context is empty, ends in whitespace, or ends in a recognized opener (, [, {, straight opening quote, curly opening quote, ¿ or ¡. An apostrophe after a letter is not an opener;
* original right context begins with a Unicode letter;
* trimmed payload is nonempty, contains at least one letter, contains only letters/whitespace and prose punctuation `.,!?;:…()[]{}"'“”‘’¿¡`, and ends in a letter or closing punctuation `.,!?;:…) ] } " ' ” ’` (without those explanatory spaces).
This character-shape predicate is conservative eligibility, not a prose/technical classifier. Digit/code/emoji payloads and in-word smart joins are ambiguous or preserved controls, never presumed target gains. Existing right whitespace/newlines/punctuation/emoji/code starts are not replaced or guessed. Left spacing uses the existing shared predicate unchanged. Hidden context must not fabricate phrase boundaries. Transcripts trim actual whitespacesAndNewlines; shared insertText never trims. Empty/whitespace-only transcript makes no edit.

The appended separator belongs to the phrase, not the host. While immediately continuing with ONE-CHARACTER attaching punctuation `.,!?;:…)]}”’` or straight quote/apostrophe, move only that owned space after the new character. Continue this ownership through the entire punctuation/closing-quote run. Straight quotes use existing quote shaping after space removal; smartQuotes=false and smartPunctuation=false preserve straight glyphs, but owned phrase-boundary relocation still applies (explicit phrase boundaries, independent of typography setting). No global punctuation behavior change. Existing/unowned spaces never gain this behavior. Other keys, return, Backspace, shared insertion, host identity/privacy/visibility/cursor/selection changes end ownership. Backspace deletes one Character as before; it is not transcript Undo. Host moves must not delete or reposition host text. Language changes may end ownership conservatively.

Every execution records full original prefix/selected/suffix; Swift Character caret and selection length; UTF-16 caret separately for UIKit comparability (not native proof); every primitive with pre/post document/caret/selection and removed text; output and phantom/automatic/phrase state after each action; policy/settings; actual dictionary filename/SHA256 and model mode separately from contentLabel. Abstract primitive reversibility does not establish native Undo grouping.
