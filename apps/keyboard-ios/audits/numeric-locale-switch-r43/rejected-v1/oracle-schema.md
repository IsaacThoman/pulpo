# R43 oracle interchange v1 (frozen before fresh author)

`python3 oracle.py validate INPUT REFERENCES` validates inputs/gold; `score INPUT REFERENCES OUTPUT` validates inputs first and emits a JSON verdict with every input row retained. Exit 0 means all rows pass; any invalid input/reference/output or failed row exits 1. XCTest process exit is not a semantic verdict.

References shape: `{ "locales": { "en_US": {"region":"US","separator":"."}, ...all four protocol locales... }, "dictionaries": { "en_US": {"available":true,"bytes":123,"sha256":"64 lowercase hex"}, "es": {...}, "en_es": {...} } }`. Foundation reference creation must be independent. Dictionary bytes and SHA must describe actual dictionary resource bytes; available must be true, bytes positive.

Output shape: `{ "schemaVersion":1, "dictionaries": { ...same measured dictionary records as references... }, "rows":[ROW,...] }` in exact input order, no omissions/duplicates/extras.

ROW required fields:
- `id`, `errors` (array of strings; empty for success), `text`, `advance` and `lists` (cumulative actual callback counts).
- `locale`: `{currentIdentifier,autoupdatingIdentifier,currentRegion,autoupdatingRegion,currentDecimalSeparator,autoupdatingDecimalSeparator}` strings. Current/autoupdating region+separator must match independent references. Identifier must identify requested locale, allowing an Xcode extension suffix (e.g. en_US@...).
- `requestedLanguage`, `loadedLanguage`: exact requested typing mode. `hostLanguage`: actual native primary language code, `es` for mode es, `en-US` for modes en_US/en_es; typing mode and host language code are distinct.
- `stack`: `{controller,keysView,engine,dictionary}` nonempty object identity strings. `dictionary` identifies the loaded requested language, `loadedLanguage` reports its selected language.
- `initialText`, `initialAdvance`, `initialLists`, `initialKeys` (all displayed actionable stable key IDs, unique), `initialGeometry`, `finalGeometry`.
- `actions`: one observation for every requested action in order, including failures; no skipped or untraced actions.

Action observation: `{index,action,beforeText,afterText,advance,lists,documentDidChangeCount,errors,hostLanguage,loadedLanguage,stack,learning}`. `action` is the exact input action object. `advance`/`lists` are actual cumulative counters. `documentDidChangeCount` is the explicit post-action host callback count (exactly 1). `learning` is `{policy,beforeCount,afterCount,beforeDirty,afterDirty}`. Counts are nonnegative integers; dirty values booleans. `policy` is `disabled` for private fields or numeric keyboard state (after any field action); otherwise `allowed`. Numeric/private actions must not change count or dirty flag. Counts/dirty flags must be continuous between action observations. Every globe action, in every layout, must preserve text and learning counts/dirty flag. Per-action errors must be empty to pass. All observed text is exact literal host text.

Geometry: `{width,height,grid,requestedOneHanded,effectiveOneHanded,effectiveWidth,keys}`. Rectangles use `[x,y,width,height]` in KeysView coordinates. All numbers finite. width equals requested width, positive height/effectiveWidth, grid and every cap/target inside KeysView, every cap inside grid. `requestedOneHanded` matches input; effective mode is off/left/right (docking may be unavailable for 320/landscape); effectiveWidth equals grid width. Keys is a nonempty array with `{id,text,cap,target,centerRoutes,targetRoutes,identityRoutes,rootRoutes}` per key. IDs unique, text string; the four routing values must be booleans and all true. target is the guaranteed independently operable hit rectangle actually sampled; centerRoutes checks the cap center, targetRoutes checks native keyIndex, identityRoutes checks native touch identity, rootRoutes checks root hit routing. Every rectangle must have positive dimensions, target rectangles cannot overlap. Portrait numeric bottom controls (zero, delete, decimal separator if decimal, globe if requested) must have >=44pt width and height. Landscape retained short targets are reported, but target width must remain >=44pt. All numeric snapshots must show digits 0..9 exactly once, delete, separator iff decimal, and globe iff requested. `initialKeys` equals initialGeometry IDs. `finalGeometry` reports actual final frames.

Additional output fields are permitted only for diagnostics; required fields are always checked. Input has a strict exact schema. Reference shape is strict. This file specifies evidence fields, not a claim of installed extension usability.
