# Public API and runner mapping (normative)

The normative contract.md and schema.json are authoritative. Runner input is one JSON suite; output is one ordered list of {id,values,baseValues,query} rows. Input and output paths are CLI arguments after the catalog path. Run: runner CATALOG INPUT OUTPUT. No payload printed by runner. search/fixture calls EmojiSuggester.search(query,limit:default48,preferring:default[:]); wrapper uses EmojiSearchQuery(query), isolated temporary UserDefaults, EmojiHistory, optional recents array and emojiTones dictionary, then EmojiSearch.results. Fixture entry emoji/name/keywords/optional tones becomes e/n/k/t with v1, Spanish aliases name inserted as s by glyph only for entries present. Non-fixture uses the shipped catalog. Missing catalog/invalid action/unsupported parameter is an execution failure, not a dropped row. preferred values and limit are signed integers in -1000000...1000000 (JSON booleans/floats are rejected); only the existing English preference effect clamps0...2. The runner rejects duplicate aliases for the same fixture glyph, whether identical or conflicting; no first/last wins rule. families is a nonempty unique array of nonempty strings; every case family references one declared string. stratum, when present, is en, es, mixed, or control; useful requires en/es/mixed. equivalentTo is a different existing case id and requires exactly equal ordered values AND baseValues; no cyclic references. Case ids are unique nonempty strings. query is a string. acceptable/forbidden/recents are arrays of nonempty strings; acceptable may be empty only with expectEmpty true and role control. expectEmpty is Boolean, default false. preferred and tones are JSON objects mapping nonempty string glyphs to bounded integers or nonempty strings respectively. maxRank is integer1...60 (not bool). role is useful/control. entries and spanishAliases are nonempty arrays of objects with exactly the required fields plus permitted optional fields. Entry keyword/tones arrays contain nonempty strings. All fixture base glyphs are unique. Aliases may target absent glyphs and are ignored. Top-level fields are exactly version/families/cases; version is integer2. All common optional fields apply to every action, but action-specific parameters are rejected on other actions. A wrapper supports no preferred map; fixture supports no recents/tones map. Invalid/unsupported schemas fail before execution, never drop rows. Fixture JSON catalogs have version fixture and category id fixture/name Fixture. Wrapper query echo is its actual buffer. search/fixture query echo is raw input. Unknown suite fields fail static schema validation; no free-form evaluator behavior. Result baseValues reports pre-tone base glyphs in the same order as values; search/fixture baseValues==values.

Contextual suggestions remain English and are audited outside this blind schema by ordinary core tests and separate paired compatibility harness. Language settings are app UI state, not a runner search parameter. Native host tests exercise them separately. Resource absence is valid decoded catalog absence of optional s, not missing whole catalog. The old40-character buffer behavior is inherited; raw inputs longer than40 are audited separately and never claimed token-equivalent after truncation. No direct native/UI action exists in this suite.
