# R48 author protocol, approved before new authorship

Use only the separately approved `domain-review/public-domain-v3.md` and clean
`domain-review/PublicDomainReference.swift`, plus this protocol. No product
source, dictionaries, earlier tests/cases/outputs, candidate run, device or
product API evaluation is permitted to the author before sealing expectations.
Independent Foundation-only reference evaluation is permitted. The examples
explicitly exposed by the map are development support, not fresh cases.

Design a compact new public TouchModel compatibility benchmark: at least twelve
distinct intent families and sixteen local/persistent family instances, with
independence and correlated checks declared. Include meaningful nonvacuous
accepted controls, target-length versus actual-sample boundaries, sparse and
normalized Character alignment, finite contributing displacement and ignored
positions, settled invalid-call conservation, learning policy and synchronous
save/reopen full-state relations. English/Spanish orthographic variety is useful;
the TouchModel API has no language-model mode, so do not manufacture three
independent resource-mode gains by repeating identical pure-model operations.

Deliver fresh fixtures, a standalone public-API Swift runner, and a strict
accounting/evaluation specification. Expose every actual operation's ID, input,
return value, last-operation status, and full weight/26offset state in raw output.
Serialize deliberate nonfinite input with explicit tags; JSON output must be
finite. Record constructor and reopen status before claiming durable state.
Include bounded learned-file regular-content inventories if used by an oracle;
do not assume arbitrary filesystem metadata is immutable. Save synchronously;
use fresh unique directories, no concurrency, no background mutation or retries.
Fresh read observation retry may be proposed only with a bounded explicit busy
rule and must retain every observation. No mutation is automatically retried.

All required literal and relational oracles must be explicit before execution:
full-state local/persistent equivalence over the same accepted operations in
order, retained settled state on intended invalid calls, successful reopen,
all26entries/dimensions, finite numbers, a declared numeric tolerance, exact
IDs/operation/count coverage and nonvacuous accepted references. Do not count a
missing/unfired/unavailable operation as an expected invalid rejection or pass.
Denominators must distinguish families, instances, individual checks, actual
calls, unavailable/errors and correlated repairs.

No product execution occurs during authorship. Independent review must check
the semantic domain, every oracle, runner action binding, full relational
enforcement and strict output accounting, including corruption rejection under
normal and optimized Python if Python is used. Declaration-only typechecking
is permitted with explicitly inert API stubs; do not import the product to
choose or repair expected outputs. Archive these preexecution checks.

The final authored fixtures, schema, runner, reference, evaluator, source,
environment and independent review are hash-frozen before one paired product
execution per version. Parent may read metadata and hash bytes while payload
remains unopened. Reveal once; retain all raw outputs and failures. No
after-reveal source/oracle/payload tuning or rerun admits this round. A failed
round remains failed even if subsequent adjudication identifies an oracle error.
