## Additional caret observation reproduction

caret-observations/check.py is a separately labelled audit of recorded facts, not a scorer or post-reveal acceptance criterion. It binds the exact original input, eight raw locale groups and two merged reports (11 files), verifies raw/merged and complete ordered ID/action inventories, then checks320 action before/after pairs (640 strict integer offsets) against their actual literal UTF16 EOF. It also verifies15 globe text/caret preservation pairs per variant. Both versions pass these observations even though the frozen baseline completion score is8/12. Runtime errors in baseline remain failures in the original scorer; this observation audit does not erase them.

The check requires an explicit path to the unchanged original accepted-v3 audit folder. It never runs app, source, Swift, Git, devices or stored paths from report contents:

```sh
python3 -B /path/to/parent-review/caret-observations/check.py --audit /path/to/numeric-locale-switch-r43/accepted-v3
python3 -B -O /path/to/parent-review/caret-observations/check.py --audit /path/to/numeric-locale-switch-r43/accepted-v3
python3 -B /path/to/parent-review/caret-observations/check.py --probe --audit /path/to/numeric-locale-switch-r43/accepted-v3
python3 -B -O /path/to/parent-review/caret-observations/check.py --probe --audit /path/to/numeric-locale-switch-r43/accepted-v3
```

Valid outputs and probe outputs are byte-identical normal/-O. The three probes change only temporary in-memory copies AFTER original byte binding: wrong EOF, Boolean caret, missing action. Each is rejected by the observation checks in both modes. No mutated raw data or gold is retained. The checker does not establish full raw schema, geometry truth, callback correctness, actual execution provenance, installed eligibility or a new semantic gain.
