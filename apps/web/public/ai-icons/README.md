# AI icons

Vendored from [`@lobehub/icons-static-svg`](https://github.com/lobehub/lobe-icons)
version 1.94.0.

Both company/lab marks and model marks live in this folder. The UI catalog that
labels and classifies them is `src/lib/ai-icons.ts`.

The inference-host marks (`azureai-color`, `baseten`, `fireworks-color`,
`ollama`, `openrouter`, `vllm-color`) are used only by the landing page's
"Use any model" section, so they are not in the picker catalog.
