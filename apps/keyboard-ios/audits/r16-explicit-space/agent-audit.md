The decisive independent source finding is **P1 inherited-text corruption**. Start with `old |tailold tehtail`, type `teh`, then move the actual caret to `old tehtailold teh|tail` before delivering its callback. The live context pair is distinct and observable. Explicit space must yield `old tehtailold teh |tail` with no deletions. Candidate EN/bilingual instead issue three deletes at the moved caret and produce `old tehtailold the |tail`, rewriting inherited text. Baseline passes the same test in EN, ES and bilingual; Spanish also preserves this particular trigger on the candidate. [Source review](source-review.md) records the exact full documents, Character offsets, primitive proof, source cause, six failing assertions and causal baseline replay. This regression is separate from the five known issues and is retained as an active protection without an allowance.

The preexisting `reconcilePendingHostChanges` short-context window heuristic can accept a live before-text ending with the optimistic before-text and a live after-text prefixing the optimistic suffix. The candidate checked its owned span against that optimistic state and deleted at the different physical caret. Local prefix/suffix arithmetic at an unchanged destination did not prove ownership at the actual destination. This observable-move failure must not be relabeled as the preexisting ambiguity where a real host change is observationally identical to an old own snapshot.
