R20 frozen pre-source contract v1

Frozen before reading insertion implementation, tests, or old R5 cases. Baseline f17109e7033eb849c9a2b98180e8c0f9d6174c3c. All inputs are synthetic. Engine-level exact full-document and caret expectations; native delivery is a separate, unverified layer.

Schema: cases[{id,category,api,prefix,selected,suffix,input,expected,caret,context?,field?,followup?}]. Prefix/selected/suffix partition the actual document; caret is a Swift Character offset in expected. api = transcript | spaced | raw | literal | emoji. transcript means actual insertTranscript (including its trim); spaced/raw mean actual insertText with spacing true/false. literal means actual key events, emoji means actual panel callback if reachable (otherwise unavailable). context = full (default) | hidden-before | hidden-after | hidden-both | queued; field = normal (default) | private | restricted. followup is literal key text after the insertion. Test runner must not preprocess insertion text or manufacture suggestion results. Every case retains complete output, primitives, conservation, and availability. Selection replacement and nil context must be modeled explicitly, not silently flattened into a caret.

Natural prose inserted at a known start/whitespace/opener boundary before an existing word needs separation on the right, without changing any existing host text. Add at most a single ASCII space when the payload ends a prose word or closing sentence delimiter and the visible suffix begins a letter. Existing whitespace/newlines are sufficient and must be preserved exactly. No space before closing delimiters or ordinary punctuation. Input-supplied whitespace is authoritative for spaced; transcript intentionally trims input. Do not assume every after-letter needs a space: technical syntax and in-word joins remain ambiguous for smart APIs and are not scored as natural success merely by adding a gap. Raw/literal calls must preserve deliberate joins exactly. No technical-parser or dictionary additions.

This contract is a hypothesis to challenge against actual API semantics before candidate freeze. Incompatible or unreachable cases remain reported failures/unavailable with reasons; no expected-output changes. Technical ambiguity has explicit unscored coverage in independent review; no invented oracle. Private/restricted flags constrain suggestions as actual APIs specify, not external insertion unless that API actually blocks it. Hidden context cannot justify a guessed suffix separator. Queued proxy delivery must conserve selected replacement, host prefix/suffix, primitive ordering and final caret. Native host Undo grouping is unavailable here and must not be claimed by a fake proxy.

Acceptance: freeze exactly one candidate plus runner before heldout disclosure; run unchanged baseline and candidate once on sealed heldout. Any regression on an executable control, conservation, selection, privacy or raw/literal join rejects the candidate. Retain every failure and unavailable case. New gain requires natural target baseline fail -> candidate exact pass. Exposed R5 cases remain development/replay only. Candidate may be rejected after heldout, never tuned. Core/service full gates must retain five known baseline issues; no dictionary/ranking/suppression/hasPathAnchor or before-existing-word correction edits. No devices, deploy, push, parent checkout edits, rawlogs, xcresults or corpora.
