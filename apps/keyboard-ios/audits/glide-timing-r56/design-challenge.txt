The candidate is plausible **only if downstream timing depends on the piecewise position–time path, rather than sample count or interior timestamps**. Retaining first and latest samples preserves a constant-position interval under linear interpolation with valid monotone times. That does not establish equivalent decoder behavior.

- **Challenge pause boundaries explicitly.** For `A@0, A@120, B@140`, retaining only `A@0` interpolates movement through the pause; retaining only `A@120` removes its arrival boundary. For `A@0, B@20, B@100, C@120`, both `B` endpoints matter to the interior dwell. Test starting, interior, and terminal pauses separately, including a terminal update delivered only by `touchesEnded`. These are analytic failures of lossy representations, not evidence of prediction improvements.

- **Specify the compression contract before implementation.** A consecutive equal-position run retains its first sample and replaces its provisional latest sample as contacts arrive. A singleton remains one sample. Suppress an exact point+time repeat without suppressing a repeated position at a later time. Define when provisional samples become visible and how transitions and termination flush them. Preserve coordinate transitions and callback/sample order; never sort by timestamp. State the memory bound per equal-position run, rather than implying bounded memory for an entire gesture.

- **Make timestamp failure behavior explicit.** Cover equal timestamps at different positions, backward timestamps within a callback and across callbacks, nonfinite values, and any unavailable-time representation permitted by the boundary. Declare whether invalid evidence disables timing for a segment or gesture, and specify the positional fallback. Do not silently sort, clamp, synthesize dwell, or divide by zero. An invalid interior timestamp can disappear during endpoint compression: validation must observe it before removal. Require deterministic output, point/time parallelism, and a documented boundary for resuming trusted timing.

- **Exercise native delivery ambiguity.** Include coalesced samples whose final sample duplicates the main touch, duplicates across callbacks, singleton and empty coalesced collections, and ordered histories spanning a dwell. Specify main-touch inclusion once. Exact-duplicate suppression must not erase a later departure timestamp. Test short gestures, entirely stationary contacts, and cancellation with a pending latest sample. Bind each case to existing action behavior: tap, alternate, double tap, delete, cursor movement, and cancel must retain their dispatch and termination behavior.

- **Separate dwell from jitter and overshoot.** Exact equality does not capture stationary-looking jitter. Include alternating nearby positions and tiny excursions, but introduce no tolerance as part of this change. Pair otherwise identical paths and durations with time concentrated at a meaningful stop versus time concentrated elsewhere. Include fast pass-through, overshoot-and-return, and dwell near an overshoot. Preservation of time evidence must not be presumed to improve the decoder’s existing stop-versus-overshoot distinction.

- **Require evidence before edits.** Record the current native callback → transport → actual decoder outputs for declared synthetic traces. Include transported points/times, existing relevant stop/overshoot diagnostics where observable, and decoded outputs with existing scores/ranks. Pair these with analytic negative controls showing what first-only, latest-only, and exact-duplicate-only handling preserve or destroy. A standalone compression simulation cannot substitute for the actual decoder path.

- **Bind tests to independent expectations and honest value criteria.** Declare callback inputs, action expectations, positional invariants, timing expectations, and evaluation criteria before candidate outputs are seen. Separate representation correctness from decoder usefulness. Unchanged predictions can demonstrate transport correctness, but cannot demonstrate recognition benefit; favorable isolated examples cannot establish general benefit. Report ties, regressions, invalid-time fallback, and action failures alongside gains. Keep all claims limited to synthetic controlled traces.

Promotion should require ordinary native/core checks, independent source and runner review, then separate source-blind fresh-author and oracle/evaluator reviews. Resolve objections before freezing exactly one baseline/candidate pair. No decoder, model, weight, or dictionary tuning; no human-use or Gboard claim.
