Settings public UI benchmark contract v1 (iPhone 18 Pro, iOS 27)
Input: schema.json, JSON version=1, 4–6 independent cases, each id/intent/actions.
Execution: SettingsUsabilityContractTests.swift is the complete immutable executor.
Each case terminates and launches the real app at home using -PKResetSettings (default English and one-handed Off). This resets settings, not learned data. Relaunch actions omit reset arguments and return to home top. No account, setup, recording, network, installed keyboard, draft/editor, focus, text selection or dictation commands exist in this interface. Do not request these.
Targets: typing-language, one-handed-setting, clear-learned-words, privacy.
reach(target,direction): performs 0–30 app scroll gestures. When the target exists but extends above 116 or below 812, it drags the right edge x=394 from y=450 by min(300, overflow+10) points in the correcting direction. Otherwise performs full app swipes up (toward bottom) or down (toward top) until target exists, is hittable, minY>=116 and maxY<=812. Logs every command success, scroll count and label. Scroll limit failures remain failures, not proof of an unreachable product control. It does not tap or change settings. Lazy list targets can be absent when far away; pick direction based on order. Failed corrections remain failures.
tap(target): taps an existing hittable target; requires prior reach except if already visible. Language and one-handed targets open native picker menus. Clear target opens confirmation. Privacy target pushes the detail page.
choose(label): taps first hittable sheet/alert/app button with exact label. Language choices: English, Español, English + Español. One-handed: Off, Left, Right. Clear confirmation destructive action: Clear Learned Words. Success alert action: OK. No Cancel button is offered on observed iOS 27 popover.
expectLabel(target,contains): checks exact case-sensitive substring in current AX label of existing language/one-handed button. This checks observable chosen state, not font size, learning store content, or keyboard output. Reach first if needed. Defaults are English/Off.
expectScreen(title): checks existence of exact-title navigation bar, sheet or alert (allowed titles in schema).
relaunch: terminates then launches without reset arguments, home top. Settings persist; scroll position is not promised.
back: taps first navigation-bar button on privacy detail; waits for Keyboard home. Only use from privacy detail.
cancelClear: taps at normalized x=.05,y=.5 of PopoverDismissRegion while clear confirmation sheet exists; verifies dismissal. This is observed outside-popover cancellation, not a nonexistent Cancel button.
All commands remain in outputs even after earlier failure. A case passes only if every command succeeds. No outcome is dropped as unavailable. No retry, interface change, fixture edits or tuning after reveal. Blank input/unknown actions are invalid before sealing. Author must not invent other controls, preconditions or capabilities.
