# Preimplementation frozen typing sweep protocol

Frozen at parent 5b972d2a before reading AGENTS.md, implementation, tests, or audits. The two JSON files define exact desired committed strings, including trailing spaces and case. Every character of `typed` is entered through the production KeyboardEngine tap adapter; no direct injection of the target token. Modes: en=English, es=Spanish, bi=bilingual. Editor cases exercise literal punctuation boundaries, not selected-context handling (owned by parent).

Development is available for diagnosis. Held-out inputs/targets may be loaded only by the final evaluation after a candidate implementation and thresholds are chosen; reveal once, compare baseline and candidate in that evaluation, and do not tune afterward. These files were authored together without repository evidence: this is implementation-blind, not independent human-blind data collection. Files are committed before inspection; hashes provide integrity, not secrecy.

Typo recovery is scored separately from clean literal protection and editor literals. Primary outcome: exact committed text per case/mode. Report every mismatch, baseline/candidate transitions, count and percent, elapsed runtime and incremental latency. A candidate must improve at least 2 development typo case/mode outcomes, introduce zero new clean/editor failures, and show at least 1 held-out typo improvement with zero new failures overall; otherwise retain no production change. Existing failures are disclosed, never silently relabeled. An independently justified editor fix can instead improve >=2 development editor outcomes and >=1 held-out editor outcome, with the same zero-regression constraint. Release suites must pass.

Content-bearing correction targets are lexically disjoint between development and held-out. Function words/context necessarily overlap; repeated modes are correlated observations, not independent samples. Both sets include English, Spanish, bilingual code switching, proper names, accents, contractions, ambiguous valid words, punctuation and casing. This synthetic convenience sample is not population accuracy, a language-quality estimate, real touch geometry/noise, or a Gboard superiority claim. No selected-text/hidden-selected-context scenarios. No dictionary/language source/binary, display accent ranking partition, language caching, Spanish layout/alternates, or dictation changes permitted.
