# Approved public map for independent boundary author

Use Swift standalone executable importing KeyboardCore (public API only). Foundation allowed. TouchModel(url: URL?) exposes weight: Double, offsets: [KeyPoint], persistenceResult: LearningPersistenceResult, isLearning: Bool, learn(_: TypedWord, intended: String, geometry: LetterGeometry) -> Bool, save(inBackground: Bool = false) -> Bool, reloadIfChangedOnDisk() -> Bool. LearningPersistenceResult .ok/.invalid/.busy etc has rawValue String. KeyPoint(x: Double,y: Double), TypedWord(text: String,taps: [KeyPoint?] = []), LetterGeometry.qwerty.center(UInt8) -> KeyPoint?, TextNormalizer.key(String) -> String. LearnedDataPersistence.storageURL(for: URL) returns authority URL. All URLs must use fresh unique temporary directories; persistent filename TouchModel.json. No device access.

Intent: preserve aligned finite local learning at arbitrary ordinary word lengths >=2 normalized bytes; persistent record limit is at most 40 actual finite letter tap samples, regardless of target length. Accept valid nonempty samples, reject mismatch/nonfinite/empty/tapless/learning-off without teaching. Sparse taps are valid. Text normalization may expand a single source character; alignment uses normalized keyed bytes and duplicated tap behavior. Persistent oversize rejects without modifying preexisting local state or files. Short and sparse bounded persistent learns save/reopen identically to local results. Bounds are per call; no algorithm or privacy policy retune. Public map is not a request to inspect implementation, resources, developer tests/results, old blind fixtures, or old witnesses.
