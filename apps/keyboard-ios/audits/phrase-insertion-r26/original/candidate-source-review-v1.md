## Demonstrated veto and refinement

The initial implementation anchored the owner only to optimistic `before`/`expectedAfterContext`. Source inspection showed that `reconcilePendingHostChanges` deliberately ignores a proxy snapshot found in `ownContextHistory`. A host replacement returning to the initial snapshot can therefore retain an owner even though its physical marker no longer exists.

Independently authored control: original prefix `pre `, suffix `later`; transcript `aloha`; physical hostReplace to `pre later`, caret 4, same document identity, no callback; then comma. The original candidate produced `pre, later` in en_US/es/en_es, deleting the protected original ASCII space. All three conservation checks failed. Surface output looking more natural does not excuse host deletion; this is exactly the kind of degradation binary pass counts can hide.

The refinement inserts the payload first and appends a marker only after exact live acknowledgement of that payload and suffix with no selection. It records origin, current anchor, suffix, and identity. Before relocation, live context must be an origin followed solely by eligible punctuation and one owned ASCII space, with matching suffix and no selection. The pre-insertion protected-prefix snapshot no longer qualifies.

Rerunning the same control on the refined source produced `pre ,later`, caret 5, no deletion primitive, and conserved/bounded true in all three stacks. A shared-empty-insertion control also passed in all stacks: transcript `aloha`, shared raw insertion `""`, comma yields `aloha ,later`; the empty shared call ends phrase ownership while retaining the old no-text-edit behavior.

Requiring acknowledgement means initial full own-lag and queued payload delivery can leave the historical fused output and no phrase owner. That is an honest target miss and conservative availability restriction. Preserve the frozen oracles and report these misses; do not reclassify them as successful separation or silently rewrite expected output. Two payload/marker insertion primitives do not establish native Undo grouping.

## Actionable findings

1. **Automatic page return must preserve the eligible apostrophe run.** The new `page` didSet clears `.phraseSpace`. An apostrophe typed while on `.numbers`/`.symbols` first relocates the marker and stores the owner, then existing end-of-`insertCharacter` behavior sets `page = .letters`, clearing that same owner. A following comma therefore cannot continue the run. Source-derived reproduction: set page to numbers, transcript `aloha` before `later`, then apostrophe and comma; required result is `aloha’, later` with smart quotes, while the present control flow yields `aloha’ ,later`. This is not an explicit other page-key action. Restore phrase ownership after the automatic return or distinguish that return from an explicit page change. Add a development source control covering smart punctuation/quote settings and both number/symbol pages. This finding was source-derived, not executed through the JSON runner because its action vocabulary has no page action.

2. **Driver bounds must include the resulting document.** `Host.apply` validates only pre-edit cursor/range bounds, then increments cursor and replaces labels using `value.count`. Swift grapheme boundaries can merge across a string concatenation. Example: prefix `a`, raw insertion of combining acute U+0301. The resulting document can have one Character while cursor becomes 2 and labels count becomes 2. The primitive/final `bounded` flag can remain true. Before freezing, validate post-edit cursor/selection and label/document Character alignment, and fail the row when the harness cannot faithfully model a grapheme-boundary mutation. Never report such execution as bounded merely because its input range was valid. A content-schema offset check alone does not prove post-mutation bounds.

3. **Keep platform observability limitations explicit.** Prior-owned-marker snapshots during own lag can be accepted conservatively, but a physical host move with a stale proxy or an external replacement reproducing an owned snapshot can be observationally indistinguishable. Source anchoring cannot establish protection from unobservable native destination changes. Retain source/controller safeguards and disclose this limit; do not expand global reconciliation or the suggestion-selection policy to claim a proof unavailable from `TextDocument`.
