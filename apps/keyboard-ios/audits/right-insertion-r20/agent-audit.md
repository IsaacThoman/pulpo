## Candidate and API scope

The rejected candidate adds one trailing ASCII space only for explicit `insertText(spacing: true)` calls at a visible original start/whitespace/opener boundary, with a letter/whitespace-only EN/ES payload, an EN/ES letter beginning the reconciled suffix, and existing policy permitting auto-spaces. It initializes fresh-engine logical context and sends payload plus separator in one insertion primitive. When it adds a gap, existing `.automaticSpace(respace: true)` handles an immediate comma or period. It leaves the R5 leading predicate and owed swipe spacing intact. Its conservative character-shape filter is **not** technical/prose recognition.

`insertTranscript` performs the actual production trim and optional casing, then opts into spacing. Direct spaced insertion preserves supplied whitespace. Default/raw insertion, emoji panel/search and literal external `.text` keys remain on their actual default `spacing: false` routes. No preprocessing shortcut, replacement dictionary, fabricated suggestion, ranking/suppression change, before-existing-word correction change or `hasPathAnchor` edit was made. The useful correction control uses real key methods: after inserting `supplies`, typing ` teh ` deletes `h/e/t` and inserts `the ` in both versions. That is control coverage, not a correction gain.

The schema omitted a language-mode field; pre-reveal metadata confirmed categories do not encode mode. The final identical driver therefore consistently uses the real production **bilingual** LanguageStack and records `en_es`. EN, ES and mixed text are exercised through that stack; these cases do not independently compare three selected modes. Existing full suites cover language switching separately.

Native transcript guards reject private fields and selected ranges, although direct engine calls execute them. Those engine cases are never claimed as native delivery. Other UIKit delivery, UTF-16 cursor behavior, real asynchronous host intervention and host Undo grouping remain unverified. No device was opened or touched, including the reserved/unrelated devices. No native build/runtime claim is made.
