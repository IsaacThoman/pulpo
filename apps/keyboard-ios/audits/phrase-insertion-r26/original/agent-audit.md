The candidate adds an optional right ASCII separator only for transcript phrases at a visible start/whitespace/opener boundary before a supported letter, with a conservatively eligible payload and prose policy. It retains actual transcript trim/capitalization and the existing shared left predicate. Supplied shared whitespace, existing right whitespace/newlines/punctuation/emoji/code starts, raw joins, and in-word ambiguity remain explicit controls. This does not infer intent from every adjacent character.

Two additional conservative necessary conditions were independently reviewed under the frozen contract's “may / only if” wording; no frozen oracle changed. Every payload letter and the suffix's first Character must fold with stable `en_US_POSIX` diacritic/case folding to ASCII letters. This supports tested accented/decomposed Spanish but is not complete Latin-script classification. Payload delivery must be acknowledged against the immutable planned prefix/output, suffix and document ID before a marker is added. Consequently unconfirmed queued/own-lag delivery remains a target miss instead of creating a potentially unsafe movable space. Eligible synchronous insertion uses two primitives; native Undo grouping is unverified.

A dedicated phrase owner stores origin, logical anchor, suffix and identity. One-Character punctuation/closing-quote runs relocate only its own separator, including with smart punctuation disabled. Straight quotes are shaped after removing that space; glyphs remain straight when quotes/typography are disabled. Ownership survives automatic apostrophe page return, but ends for ordinary letters, shared insertion (including empty), explicit page/shift actions, return, Backspace and observable destination/privacy changes. Every relocation phase rechecks its immutable destination; interruption after deleting the marker aborts the remaining punctuation action. Pending callbacks cannot make an adopted private/foreign context bless the old phrase plan. No suggestion selection, ranking, dictionary, path, global reconciliation, or explicit-before-word correction policy changed.
