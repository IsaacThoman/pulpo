# Frozen compact layout UX protocol

Frozen at baseline e1865f3f before relevant implementation inspection. Scope: production UIKit keyboard controller, root, suggestion bar and keys; exclude app navigation/draft retention, core text/suppression experiments. Assigned simulator: iPhone18Pro 7E1D7979-7307-4C53-8466-BB41154B383C. No other devices, physical deployment or push.

Development: 27 predeclared combinations in development-cases.json, English/Spanish/bilingual, 320/402 portrait and 690 landscape logical widths, full/left/right docking. 320 uses largest accessibility content-size category and bold trait; other widths use default traits. Test layout in a real UIKit window/controller with actual hitTest and action dispatch, production constraints and layout passes. Later installed interaction/rotation checks use the assigned simulator where available.

For each case inspect visible language, Undo (when offered), microphone, mode, shift/delete/space/return and representative letter/accent controls: positive in-bounds tappable area, center hit delivered to correct control or its descendant, no overlap covering a visible control, readable meaning via title or accessibility label. Exercise language presentation/dismissal, letters/symbols/emoji/letters and docking/restore where supported. Input output must establish that keys work. Record unsupported/unavailable paths instead of silently skipping. Truncated suggestions are allowed if intentional; distinguish loss of affordance meaning from elision of long content. No universal 44pt minimum for letter keys.

Baseline first; change production only for a reproduced user-visible defect with a general cause. Freeze candidate commit before reading fresh verification outcomes. An independent author will freeze fresh inputs without reading implementation or development outcomes. Run fresh cases only after candidate freeze. Regression checks cover native layout/interactions/modes plus relevant existing native tests. Keep failed gates, counts, source review, costs and tool limitations. No raw screenshots, build logs, result bundles or large corpora in Git.

Limits: simulated widths and programmatic hit testing establish layout/routing evidence, not physical-phone/human reachability, VoiceOver speech or comfort. Trait injection does not establish system-wide settings behavior. Installed extension AX may be unavailable on iOS27; disclose geometry/in-app fallback without changing product to appease harness.
