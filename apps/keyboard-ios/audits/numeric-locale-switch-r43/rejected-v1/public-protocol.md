# R43 public workflow protocol v1
Public observable contract: contract.md. This protocol is frozen before fresh inputs. No source, tests, resources, developer cases or results are part of authoring input.

Input is a JSON array of 12–24 workflows with unique id, locale (Foundation identifier, one of en_US, es_ES, es_MX, ar_EG), language (en_US, es, en_es typing mode), keyboard (decimal, number, asciiNumber, standard, email, url), globe Boolean (host requires input switch control), width number (320,375,393,430,852), oneHanded (off,left,right), privateField Boolean (secure text trait), initialText string, actions array, expectedText string, expectedAdvance integer, expectedLists integer.

Each action is {kind, value?}:
- tap: value is exactly one displayed character, literal insertion through native KeysView touches. No arbitrary text insertion or hidden fallback. Required key missing makes row fail.
- key: value is a stable public key identifier. key-numbers selects numeric punctuation page; key-symbols selects symbols; key-letters returns letters; key-space types space; key-return invokes the return key. Globe via generic key is forbidden. Blank is not actionable.
- delete: no value, single backspace through native key touch.
- globeTouch: no value; native KeysView began and ended UIEvent callbacks, exactly two host list callback invocations, no actual OS menu guarantee. Does not advance host counter.
- globeAX: no value; native KeyView accessibilityActivate with one host advance callback. No spoken VoiceOver claim.
- refresh: no value; controller documentDidChange with unchanged host traits/document.
- field: value is a supported keyboard kind; same native field changes keyboard type and calls controller documentDidChange. This is not a different-document or OS focus claim.
Each action is followed by an explicit recorded host documentDidChange callback, matching a synchronous host after its edit. Cursor is at end; selection/caret moves, holds, cancel, touch movement, Return-based form progression, arbitrary language/globe/private/locale/width changes within a workflow are outside this protocol. Unknown operations/values fail. Row outcomes include exact literal text and observed callbacks. Unsupported requested keys must fail; do not silently skip them or accept an error as completion.

Executor runs one locale per fresh XCTest host process using Xcode -testLanguage and -testRegion, asserts effective Foundation current/autoupdating region and decimal separator. A benchmark row does not set locale in a running process. Real en_US/es/en_es dictionaries must be available, load successfully, and remain selected; native stack/learning observers are mandatory. Numeric/private actions retain no-learning; ordinary prose can learn (a positive observer control is handled in smoke, not a required benchmark gain).

Layout guarantees to score: exactly ten digit actions in numeric layouts, required numeric globe present iff requested, all caps inside grid, all initial and final keys center-hit route to grid, sampled guaranteed target rectangles route to intended key (native keyIndex plus touch checks), portrait numeric bottom controls have >=44pt width/height guaranteed rectangle. Existing landscape short vertical targets are reported (no blanket 44pt pass). One-handed requested/effective width is reported; docking can be unavailable at 320/landscape. Geometry probes are separate from document workflows and do not alter host text.

Oracle gates: nonempty all rows, matching IDs/order/no omissions, no runtime errors, actual process locale region+separator matches independent Foundation value, nonempty dictionaries with hashes and true loaded requested language, exact text/advance/lists outcomes, no document edit during either globe route, numeric/private no-learning counts+dirty change absent, complete actions traced including failures. All unchanged/failed/unavailable rows remain in denominator. This is workflow completion coverage, never model accuracy/speed or installed OS menu proof.

Frozen public capability inventory for this restricted executor:
- Initial page letters. `field` changes keyboard and resets to letters if kind differs; unchanged keyboard preserves page. `refresh` and ordinary synchronous host callbacks preserve page. No capitalization (native field autocapitalization=.none); no Shift action in protocol. Ordinary prose uses ordinary smart punctuation/autocorrect defaults, so author should use stable literal controls; validator rejects gold outside literal protocol semantics rather than guessing predictions.
- number/asciiNumber: digits 0–9/delete, required globe iff requested; no pages or space/return.
- decimal: digits 0–9/delete/region decimal separator, required globe iff requested; no pages or space/return. Separator and globe must be simultaneous.
- standard/email/url letters: lowercase qwertyuiop/asdfghjkl/zxcvbnm; key-numbers available. Email additionally @ and .; URL additionally . and /. Standard/email have key-space; URL uses punctuation shortcuts instead of space. key-return inserts newline (no form-navigation promise).
- numbers page: digits 1234567890, punctuation -/:;()$&@" and . , ? ! '. key-symbols, key-letters, delete. symbols page: []{}#%^*+= and _\|~<>€£¥• and . , ? ! '; key-numbers, key-letters, delete. Bottom shortcuts same keyboard kind on all prose pages. key-space and key-return after ordinary engine behavior return page to letters; normal single literal space and newline are the only expected forms in this protocol (do not use double space, smart quotes, ambiguous correction controls as new oracle guesses).
- Prose pages expose required globe iff requested. This is callback evidence only.
- Secure fields keep the same available controls and literal no-learning policy. Field kind and privacy are independent. Numeric changes do not alter text/caret. Switch callbacks do not alter text/caret.
