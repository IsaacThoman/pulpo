# Candidate selection, before held-out reveal

One selected candidate after a pre-reveal source-review refinement: extend the existing literal-token policy with a path anchor at the beginning of the whitespace token: Unix `/` with a subsequent directory separator, `./`, `../`, `~/`, two backslashes (UNC), or an ASCII drive letter followed by colon and slash/backslash. Recompute from the live cursor context; no persistent literal state. No any-dot/any-slash rule, leading-option rule, dictionary edits, or ranking/before-existing-text policy changes. Bare filenames, bare relative paths and options intentionally remain ambiguous and unchanged.

Development, all 38 frozen templates per actual stack: English **20 → 25**, Spanish **19 → 22**, bilingual **23 → 30**. Zero previously passing failures in every mode. Every output change is in an explicitly anchored technical case or the known `/tmp/notes.txt` diagnostic. All 13 ordinary-boundary templates retain identical full outputs, alternatives and automatic-correction proposals, including failures. Raw literal replays **114/114** on both builds. No held-out inputs or results have been read at this point; independent author reports 44 sealed templates, SHA-256 `e31e9142f8cd3cb8e77ed9b2ad1cf673fdf0d39eb50ddf66badf092e13a4a45c`.

Six focused test methods (30 parameterized invocations) pass: syntax positives/negatives, literal path text/learning, EN/bilingual prose and Undo/marker deletion, ES/bilingual slash prose, and real selection/suffix/inside-word editing. Entire candidate package: **445 core + 3 service tests**, passing with five already-marked known issues. Data regressions: **11** passing tests. Native controller execution is unavailable by task instruction; no device access occurred.

Frozen-oracle limitations retained without editing inputs: spaced sentence cases expect lowercase despite normal automatic capitalization; marker deletion cases similarly expect lowercase at document start; Undo oracle incorrectly retains the delimiter. These are failures on both builds and remain in all denominators. Focused tests assert the actual correct capitalization and Undo behavior independently. All modes run every case, including English typo expectations in Spanish-only and Spanish accent expectations in English-only, so the absolute rate is a mixed-purpose diagnostic, not population accuracy. The prose preservation claim also compares exact outputs/alternatives/proposals, which does not depend on those oracle defects.

Known R11/exposed examples are development diagnostics only. Development gains are not fresh blind evidence. Root syntax can still be used intentionally in prose; this rule makes a syntactic policy choice, not an intent classifier. No per-word/extension exception or blanket disable was tried. Retain the candidate only if the one sealed reveal corroborates useful technical gains without ordinary/control losses. Do not tune source, runner, cases or expected documents after reveal.
