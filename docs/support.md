# Support

## Get help

For the Pulpo apps and the hosted [pulpo.baby](https://pulpo.baby) service, report a problem or request help in the [Pulpo GitHub issue tracker](https://github.com/IsaacThoman/pulpo/issues). Do not include passwords, bearer tokens, private conversation content, or provider keys.

## Self-hosted instances

If you use another Pulpo instance, contact that instance's operator for account approval, password resets, retention, provider configuration, billing, availability, and data requests.

## Useful diagnostics

Include the app version, your device and operating system version, the instance URL, the action you attempted, and the displayed error code. You can switch instances or clear downloaded data from Settings without sharing secret credentials.
